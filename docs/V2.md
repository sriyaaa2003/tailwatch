# v2: what ranks bursts better on unseen groups

`experiments/extra_features.py`, `experiments/regularised_learners.py`, `experiments/leaf_sensitivity.py`. Same protocol as above (leave-one-group-out, original features, validation inside the training groups), PR-AUC pooled over the held-out groups.

| model | msData (4.0% positives) | 5G traces (3.8% positives) |
|---|---|---|
| repo model: boosted trees, balanced class weights | 0.334 | 0.121 |
| boosted trees, no class weights, 15 leaves, 100 rows per leaf, L2 | 0.360 | 0.154 |
| random forest (balanced, 20 rows per leaf) | 0.366 | 0.138 |
| **ExtraTrees**, settings chosen by a nested leave-one-group-out inside the training groups only | **0.385** | 0.141 |
| logistic regression (scaled, balanced) | 0.304 | - |

ExtraTrees minus the repo model: **+0.051 on msData (95% CI +0.028 to +0.067)** and **+0.020 on the 5G traces (+0.010 to +0.030)**, blocks of 60 s resampled.
On msData it is better in all five held-out mobility patterns; on the 5G traces the best model differs (the plain boosted model is higher pooled, 0.154), so the safe reading
is that **simpler, randomised or more regularised learners generalise to unseen groups better than the class-weighted boosted model, and which one is best depends on the data set**.
Nested selection always chose large leaves (60 rows), and a sensitivity run on msData shows a plateau from 20 to 60 rows per leaf (0.381, 0.380) and a decline beyond (0.375, 0.362, 0.341 at 120, 250, 500).

What did **not** work, stated plainly:
- **26 extra burst-history features** (windows to 300 s, exponentially weighted load, time since the load last passed 30% and 60% of the burst level, counts above those levels, rolling 90th percentile) made every model worse on msData: boosted trees 0.334 to 0.243, CatBoost 0.334 to 0.299, ExtraTrees 0.383 to 0.372. They help the model describe the training groups' own dynamics and do not transfer to a new mobility pattern.
- **CatBoost** matched the repo model (0.334) and **averaging models** did not beat ExtraTrees alone (rank-averaged ExtraTrees + plain boosting 0.370).
- The rows above are ranking only. The calibration, alert-cost and interval results of the original study are unchanged; the interval finding (80% intervals cover the event rows far less than 80%) is not addressed by a better ranker.
